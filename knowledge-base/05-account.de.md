# Kundenkonto und Bestellung

## Kundenkonto eröffnen
Senden Sie uns Firmenname, Rechnungsadresse, USt-IdNr. (oder Gewerbenachweis) und eine
Ansprechperson über das Kontaktformular auf unserer Website. Konten werden in der Regel
innerhalb eines Werktags freigeschaltet.

## So bestellen Sie
- Onlineshop (rund um die Uhr)
- E-Mail: orders@muster-gmbh.example
- Telefon während der Servicezeiten

## Bestellnummern und Status
Jede Bestellung erhält eine Nummer wie S00012. Mögliche Status:
- Angebot: noch nicht bestätigt
- Bestätigt: Auftrag angenommen, Lieferung wird vorbereitet
- Berechnet: Rechnung wurde erstellt
- Storniert
